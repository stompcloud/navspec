# Security Policy

## Supported Versions

| Version | Security support |
| ------- | ---------------- |
| 0.1.x   | Best effort      |

NavSpec is maintained on a best-effort basis. There are no guaranteed
response times or guarantees that a vulnerability will be fixed.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately using
**Report a vulnerability** under this repository’s **Security and quality**
tab.

Include the affected version, steps to reproduce, and potential impact if
known. If you have a proposed fix, please include it in the private report.

Please avoid opening a public issue or pull request with vulnerability
details before discussing disclosure with the maintainer.
